Fulstack webdevelopment and full stack

Full stack web development simply means building both the visual side of a website (front-end) and the behind-the-scenes logic and data (back-end). ("Fullstack" and "full stack" mean the exact same thing.)

User/client, server Archistructure.?

Client-server architecture is a computing model where a client (the user's device or browser) requests data or services, and a server (a powerful remote computer) processes that request and sends back a response.

UI & UX?

UI (User Interface) is how a website or app looks and feels visually, while UX (User Experience) is how easy, smooth, and logical it is to use.

Responsive design?

Responsive design is a web design approach that makes websites automatically adjust their layout, images, and text to look good and work smoothly on any screen size—from mobile phones to tablets and desktop monitors.

Static an dynamic?

A static webpage shows the exact same fixed content to every visitor, while a dynamic webpage generates customized, changing content in real time based on the user, time, or database updates.

Front-end and Back-end development?

Front-end development builds the visual, interactive part of a website that users see and touch in their browser, while back-end development builds the behind-the-scenes server, logic, and database systems that power it.

Front-end Technologies?

Front-end technologies are the programming languages, frameworks, and tools used to build the visual layout, design, and interactive features of a website that users see and interact with in their browser.

frame work?-> react, Vue Js, Angular Js.Java API-> Spring Boot.

A software framework is a pre-built foundation of reusable code, tools, and rules that gives developers a standard structure so they do not have to build common features from scratch.

Python API-> Flask, Djongo,Fast API.

Python API frameworks are back-end toolkits that allow developers to build web servers and REST APIs using Python—connecting front-end apps (like React) to server logic, databases, and AI/ML models.

Back-end Technologies?->Java,python,Node js, Rupy,php.

Back-end technologies are the server-side programming languages and runtimes that handle an application's behind-the-scenes logic, user authentication, security, and database communication.

Frame work->Djongo,fastAPI,SpringBoot,MernStack,Node js, Express Js.

These terms cover back-end frameworks, runtimes, and a full-stack bundle used to build web servers, APIs, and complete web applications.
